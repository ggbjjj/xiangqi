# 棋谱数据库

`dataset.sqlite3` 已导入此次实际下载的数据，完整保留原始 ZIP/CBL 文件和逐局原始内容。

| 内容 | 数量 |
|---|---:|
| 原始记录（含不同分类下的重复棋谱） | 61,857 |
| 通过规则校验并去重的可训练大师棋谱 | 27,759 |
| 训练集 | 24,916 |
| 验证集 | 1,440 |
| 测试集 | 1,403 |
| 可训练棋谱原始总半回合数 | 2,392,304 |
| CBL 原始记录，等待主线解码 | 3,389 |

数据库表：sources（来源/授权声明）、source_files（原始文件 BLOB/校验和）、raw_records（逐局原始记录、状态与错误）、games（标准初始 FEN、完整动作 JSON 数组、总步数、划分）、metadata（编码与校验口径）。每局一个 games 样本。

CCPD 58,468 条原始棋谱中：53,607 条记录映射到 27,759 局有效样本；77 条为空或文本结构未通过，另 1 条走法校验失败；其余 4,783 条电脑对局或其他题型保留原文、排除本轮大师棋谱预训练。CNVCS 的 3,389 条 CBL 已存库，status=pending_decoder，不计入可训练数量。详见 import_report.json。

去重依据为规范初始局面与完整动作序列。相同初始局面及前 24 步组成 split_group，按稳定哈希约 90%/5%/5% 划分；该组不会跨集合。短于 24 步采用全部动作。仍可能存在跨集合共享开局或不同长度的同局摘录，指标应理解为棋谱预测能力，不能宣称棋力等级。

入库校验逐步检查棋子规则、己方将帅安全与轮到谁走；不套用桌面游戏的三次重复/120步不吃子自动结束条件，也不执行正式比赛长将长捉裁决。错误整局隔离，绝不静默保留错误前缀。

数据库保留 K 个完整动作；T 在读取时决定，保留前 min(K,T) 个连续训练对，补零至 T，不跳步压缩。X_t 是执行 a_t 前的局面；最终无后续动作的终局不额外作标签。编码：红黑绝对位置 14 通道 + 红走=1/黑走=0 的第 15 通道；方格号 9*r+c，动作号 90*src+dst。

重建/断点导入：`python -m data_pipeline.import_records --workers 4`。再次运行跳过已入库文件和已校验记录。来源文件位于 pretrain_data/source_survey_20261024。
