## 下次继续训练

参见上级 [TrainingRecords/README.md](../README.md)，推荐使用项目根目录的 `resume_train.py`。在远程项目根目录：

```bash
export OMP_NUM_THREADS=4
export MKL_NUM_THREADS=4
uv run --locked --extra gpu python resume_train.py --check-only
uv run --locked --extra gpu python resume_train.py --epochs 2
```

不传 `--epochs` 默认也是 2；传 10 则继续第 2 至第 10 轮。入口会核对检查点、恢复状态与数据划分，并为此次续训建立独立日志目录，保留原始配置和未保存训练的日志。

等价的核心恢复参数为：

```text
--resume ddba0b0639364a4cbd663f51ab74d3d7 --epochs 2 --T 120 --batch-size 128 --micro-batch 16 --workers 4 --seed 42 --device cuda --precision auto
```

这里 `--resume` 必须保留；单独运行没有 `--resume` 的普通训练命令会初始化新模型。当前归档只是核验与保存，没有在本地启动第二轮训练。
