# 中国象棋 2020 版棋规研究草稿

**状态：未完成，未接入客户端、合法动作掩码、训练或自对弈。**

本目录保留此前按中国《象棋竞赛规则（2020版）》判定长将、长捉责任的研究，未在正式程序启用。用户之后改为自定义的简化规则：同一循环连续重复，使相同局面与走方第三次出现时，由当前走方变招，不区分攻守责任。正式实现见根目录 `repetition.py` 和 [指令.md](../../指令.md)。

本目录草稿仍会误判部分正式棋例，且某些战术搜索耗时过长，因此未接入运行时。**正式程序已使用上述连续循环强制变招规则；本目录的完整赛事责任裁决仍未交付。**

## 文件

- `cases.json`：原规则第八、九章 79 个棋例的局面、334 步着法及着法类别转录。局面从原书图片提取，记谱经现有走法解析器校验；仍须逐例复核。`responsible` 是初步文本提取，可能包含正文中另一个变例的结论，不能直接作为最终裁决标签。
- `xiangqi_rules/`：独立的历史与战术判定草稿，仅供研究脚本显式导入，不属于安装包。
- `evaluate_cases.py`：逐例比较原书着法类别，单个棋例使用独立子进程；超时单独报告，不算通过或判和。
- `last_partial_report.json`：最后一次未完成的诊断记录，包含对应代码哈希。仅完成 92 步比较，其中 16 步类别不一致，不能当作全部棋例的通过率。

依据：中国象棋协会审定的[《象棋竞赛规则（2020版）》原文 PDF](https://wdd66d.top/downloads/qigui/Xqqg2020.pdf)，重点为第 23—26 条及所附棋例。PDF 存于本地忽略目录 `.test-tmp/rules-reference/`，不随 Git 上传。

## 手动复现

在项目根目录执行，支持重复指定 `--case`；不指定则检查全部棋例：

```powershell
uv run --locked --extra cpu python research/cn2020/evaluate_cases.py --case 图6 --case 图7 --timeout-seconds 5
```

脚本按棋例输出通过、不一致、超时或错误，并把完整报告保存到 `runs/rules-cn2020/`。它不启动训练，不生成对局，不操作模型库和棋谱库。超时只是计算资源限制，不是棋规裁决。
